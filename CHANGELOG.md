# Changelog

## 0.1.0

- Added validated three-fraction datasets and paired condition-by-fraction models.
- Made within-fraction median-of-ratios normalization the default.
- Added explicit polysome, monosome, and input contrasts with stable effect direction.
- Added gene-level diagnostics, input fingerprints, and provenance sidecars.
- Defined the shared-dispersion Wald model as a transparent working model.
- Added a frozen, resumable simulation benchmark against R DESeq2, edgeR,
  a log-ratio baseline, and FracFixR's native tests and fraction reconstruction.
